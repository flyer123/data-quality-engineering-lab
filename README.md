# Data Quality Engineering Lab

## Overview

Data Quality Engineering Lab is a production-style portfolio project that demonstrates how to design, implement, monitor, and maintain trustworthy data pipelines.

The project simulates a retail company's analytical platform and focuses on data validation, observability, monitoring, incident response, and quality reporting.

## Goals

* Build a reusable data validation framework in Python
* Measure and monitor data quality over time
* Detect schema drift and data anomalies
* Simulate production data incidents
* Produce operational reports and postmortems

## Technology Stack

* Python 3.13
* PostgreSQL
* Pandas
* Docker Compose
* pytest
* mypy
* Ruff
